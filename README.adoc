:toc:
:toclevels: 3
:icons: font

== Overview

This repository provides programming samples and **custom applications** for working with **SICK Visionary cameras** (Visionary-T Mini CX and Visionary-S CX).

It is based on and extends the official SICK reference repository:

- https://github.com/SICKAG/sick_visionary_samples.git

The original examples (device discovery, login, configuration, streaming, storage) are preserved.  
On top of those, this repo introduces:

* `Application/` – custom libraries (reusable modules)  
* `main_application/` – main program components with Qt5 UIs and inter-process communication  

[IMPORTANT]
====
This project is **custom developed and tested for Windows only**.  
Ubuntu/Linux builds are **untested**. Users may attempt a port with small CMake/network tweaks, but no official support is provided.
====

== Supported Devices

* Visionary-T Mini CX (V3S105-1AAAAAA, FW ≥ 2.1.0, 3.0.0)  
* Visionary-S CX (V3S102-1AAAAAA / V3S102-1AABAAB, FW ≥ 6.0.0, 6.5.0)  

== Tested Environment

* Windows 10/11  
* Visual Studio 2022 (MSVC 19.x)  
* CMake ≥ 3.24  
* vcpkg (dependency management)  
* Python 3.x with pip (for Python samples)  
* Visionary-S

== External Libraries Used

The project relies on the following libraries:

* **OpenCV** – image capture and processing  
* **PCL (Point Cloud Library)** – 3D point cloud filtering and computation  
* **Eigen3** – linear algebra and transformations  
* **open62541** – OPC UA communication with CODESYS PLCs  
* **Boost.Process** – managing and spawning processes  
* **Qt5 Widgets** – graphical user interface for both processes  
* **VTK** – 3D visualization of filtered objects  

These are installed easily via **vcpkg** on Windows:

[source,powershell]
----
vcpkg install opencv[core,ffmpeg]:x64-windows
vcpkg install pcl:x64-windows
vcpkg install eigen3:x64-windows
vcpkg install open62541:x64-windows
vcpkg install boost-process:x64-windows
vcpkg install qt5:x64-windows
vcpkg install vtk:x64-windows
----

== Python Dependencies (for samples only)

== Custom Application (Windows Only)

The custom application integrates **Visionary camera data** with an external **PLC** using OPC UA, while providing **Qt5-based UIs** for real-time control and monitoring. The purpose was to obtain the position of the object feed over the conveyor and send it to the PLC for a pick and place application.

* **Communication.cpp**  
  - Manages the **OPC UA connection** with a CODESYS PLC. Application name `comm_worker`.
  - User specifies PLC **IP address** and **OPC UA paths**.  
  - Qt5 UI displays connection state and configuration options.  

* **PositionData.cpp**  
  - Captures frames from the Visionary camera. Application name `pos_worker`  
  - Performs **object filtering**, **position computation**, and **timestamp processing**.  
  - Qt5 UI allows the user to **fine-tune filtering parameters** for the field of view.  

* **app.cpp**  
  - Acts as the **main entry point**. Application name `main_app`.  
  - Starts both `Communication` and `PositionData` processes concurrently.  
  - Uses **inter-process communication (IPC)** to coordinate tasks.  

=== Workflow

1. Launch `main_app`.  
2. Two processes start in parallel:  
   * **Communication** handles PLC connection via OPC UA.  
   * **PositionData** handles camera capture and filtering.  
3. User adjusts **filter parameters** in the PositionData UI.  
4. User sets **PLC IP and OPC UA pathways** in the Communication UI.  
5. Application sends **object position data** with timestamps to the PLC.  

Pipeline:  
`Visionary Camera → PositionData (filter + compute) → IPC → Communication (OPC UA) → PLC`

== Build (Windows)

**Preferably use Visual Studio**. However, the following are commands for PowerShell.

[source,powershell]
----
git clone https://github.com/VasuPadsumbia/SICK-PointCloud.git
cd SICK-PointCloud
git submodule update --init --recursive

cmake -B build -DCMAKE_TOOLCHAIN_FILE=C:/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
----

== Run

* **C++ Welcome demo** (from original samples):

[source,powershell]
----
.\build\Release\welcome.exe -i 192.168.1.10 -d Visionary-S
----

* **Custom application** (from `main_application/`):  
  Run the executable built from `app.cpp` to start both processes.  
  - Use **Communication UI** → connect to desired PLC (IP + OPC UA path).  
  - Use **PositionData UI** → filter objects and adjust parameters interactively.
